# Evaluation and Limits

The repository includes automatic retrieval and use-case evaluation artifacts.
These scores describe the supplied heuristic evaluation set; they are not proof
of factual accuracy, safety, latency, robot control, or learning gain.

Before publishing a production claim, record:

- the exact model, embedding model, and collection used;
- the approved corpus version and its license;
- human review of safety and API answers;
- failures, irrelevant retrievals, and citation quality;
- whether any output is allowed to cross into an ARC command interface.

Do not treat the fallback extractive response as a safety guarantee.
